# 09 — เช็กลิสต์ก่อนกดส่ง

พิมพ์ออกมาแล้วติ๊กทีละอัน ข้อที่มี ⚠️ คือข้อที่ถ้าไม่ทำ = โดนตีกลับแน่นอน

## ก่อนเริ่มลงทุนเงิน

- [ ] ⚠️ ส่งอีเมลขออนุญาตค่ายแล้ว (`08-legal.md` §8.2 ทาง A)
- [ ] ตัดสินใจแล้วว่าถ้าไม่ได้รับอนุญาต จะเดินทาง B หรือ C
- [ ] ชื่อแอป `48thDB` ยังว่างใน App Store และ Play Store (ค้นดูในสโตร์)

## โค้ดและข้อมูล

- [x] `index.html` เล็กลงเหลือไม่เกิน ~300 KB (ตอนนี้ 2.7 KB)
- [ ] ⚠️ Firestore Rules ไม่ใช่ `allow read, write: if true` แล้ว
- [ ] ข้อมูลที่เปลี่ยนบ่อย (งาน/เพลง/เซมบัตสึ) อยู่ใน Firestore ไม่ใช่ในโค้ด
- [ ] มีหน้าแอดมินสำหรับเพิ่ม/แก้งานจากมือถือ
- [ ] แคช `meta/version` ทำงาน (เปิดแอปครั้งที่สองยิง Firestore แค่ครั้งเดียว)
- [ ] มีสคริปต์สำรองข้อมูล และทดลองรันแล้วได้ JSON จริง
- [ ] `serviceAccount.json` และ keystore อยู่ใน `.gitignore` ⚠️ หลุดขึ้น git = ต้องเปลี่ยนคีย์ทั้งหมด
      (ตอนนี้ `.gitignore` กัน `node_modules/` กับ `.smoke/` ไว้แล้ว ยังไม่มีสองไฟล์นั้นในเครื่อง)

## บัญชีผู้ใช้

- [ ] Bookmark/โอชิ เก็บต่อเนื่อง ปิดแอปเปิดใหม่ยังอยู่
- [ ] สมัครสมาชิกทีหลังแล้วโอชิเดิมไม่หาย (link anonymous account)
- [ ] ⚠️ มี Sign in with Apple (เพราะมี Google Sign-In)
- [ ] ⚠️ มีปุ่มลบบัญชีในแอป และลบได้จริง
- [ ] ใช้แอปได้โดยไม่ต้องล็อกอิน (Apple ไม่ชอบบังคับสมัครถ้าไม่จำเป็น)

## ฟีเจอร์เนทีฟ (กัน Guideline 4.2)

- [ ] ⚠️ แจ้งเตือนวันเกิด/งาน ทำงานจริงบนเครื่องจริง
- [ ] ขอสิทธิ์แจ้งเตือนตอนผู้ใช้กดเปิดฟีเจอร์ ไม่ใช่ตอนเปิดแอปครั้งแรก
- [ ] เปิดโหมดเครื่องบินแล้วยังใช้ได้ทุกหน้า
- [ ] ปุ่มเพิ่มลงปฏิทิน
- [ ] แชร์การ์ดเป็นรูป
- [ ] Haptics ตอนกดปุ่มสำคัญ
- [ ] (ถ้าทำได้) Widget หน้าโฮม

## ทดสอบบนเครื่องจริง

- [ ] iPhone รุ่นมีติ่ง — ไม่มีอะไรโดนติ่งบัง ไม่มีแถบขาว
- [ ] iPhone รุ่นเล็ก (SE) — ตัวหนังสือไม่ล้น ปุ่มไม่ซ้อน
- [ ] iPad (ถ้ารองรับ) — ไม่ใช่แค่แอปโทรศัพท์ยืดออก
- [ ] Android ปุ่ม back ปิดโมดัลก่อน ไม่ใช่ปิดแอป
- [ ] หมุนจอ (ถ้าล็อกแนวตั้งไว้ ต้องล็อกจริงทั้งสองแพลตฟอร์ม)
- [ ] ตัวหนังสือใหญ่พิเศษ (Settings → Accessibility → Larger Text) — ยังอ่านได้ ไม่ทับกัน
- [ ] โหมดมืด/สว่าง สลับแล้วไม่มีข้อความจมพื้น
- [ ] เน็ตช้า/หลุดกลางคัน — ไม่ค้างจอขาว มีข้อความบอกสถานะ
- [ ] ⚠️ ไม่มี console error สีแดงตอนใช้งานปกติ (Safari → Develop → เลือกเครื่อง)

## ลำดับที่ควรทำถ้าเริ่มพรุ่งนี้

1. **วันนี้** — ส่งอีเมลหาค่าย (`08`) + แก้ Firestore Rules (`02` §3.3) สองอย่างนี้ใช้เวลารวมไม่ถึงชั่วโมง แต่สำคัญที่สุด
2. **สัปดาห์นี้** — แยกไฟล์ + เอารูปออกจาก base64 (`02`)
3. **สัปดาห์หน้า** — ย้ายข้อมูลขึ้น Firestore + ทำหน้าแอดมิน (`02`, `05`)
   → ถึงตรงนี้ ต่อให้ยังไม่ทำแอป ชีวิตคุณก็ดีขึ้นมากแล้ว เพราะอัปเดตงานจากมือถือได้
4. **หลังจากนั้น** — ค่อยตัดสินใจเรื่องแอปสโตร์ตามคำตอบจากค่าย

ระหว่างทางติดตรงไหน บอกผมได้ทุกขั้น — จะช่วยเขียนโค้ดให้เลยก็ได้
