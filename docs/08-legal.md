# 08 — ลิขสิทธิ์ ความเป็นส่วนตัว และเรื่องที่ต้องเคลียร์ก่อนขึ้นสโตร์

> ผมไม่ใช่ทนายความ ข้อมูลนี้เป็นความเข้าใจทั่วไปเพื่อให้คุณเตรียมตัวได้ถูกทาง
> ถ้าแอปเริ่มมีคนใช้เยอะหรือมีรายได้ ควรปรึกษาทนายจริงสักครั้ง

## 8.1 เรื่องที่เสี่ยงที่สุดของโปรเจกต์นี้

แอปนี้ใช้ **รูปโปรไฟล์เมมเบอร์, โปสเตอร์งาน, ชื่อวง BNK48 / CGM48, ชื่อเพลง**
ทั้งหมดนี้เป็นทรัพย์สินของ **บริษัท อิสระในการจัดการศิลปิน จำกัด (iAM)**
และผู้ถือสิทธิ์ต้นทาง (AKS / Vernalossom สำหรับสิทธิ์แฟรนไชส์ 48 Group)

สถานะตามกฎ:

| สิ่งที่ใช้ | ความเสี่ยง | หมายเหตุ |
|---|---|---|
| ข้อเท็จจริง (วันเกิด ชื่อ ทีม วันจัดงาน ลำดับเซมบัตสึ) | **ต่ำ** | ข้อเท็จจริงลอก ๆ ไม่มีลิขสิทธิ์ในตัวมันเอง |
| รูปถ่ายโปรไฟล์ทางการ | **สูง** | เป็นงานอันมีลิขสิทธิ์ของค่าย/ช่างภาพชัดเจน |
| โปสเตอร์งาน / อาร์ตเวิร์กปก | **สูง** | เหมือนกัน |
| ชื่อ "BNK48" / "CGM48" / โลโก้ | **สูง** | เครื่องหมายการค้าจดทะเบียน |
| เพลง / คลิป | **สูงมาก** | อย่าฝังไฟล์เสียง/วิดีโอเด็ดขาด ลิงก์ไป YouTube ทางการแทน |

Apple Guideline **5.2.1** เขียนว่า แอปต้องไม่ใช้ทรัพย์สินทางปัญญาของบุคคลที่สาม
โดยไม่ได้รับอนุญาต และ **5.2.5** ห้ามแอปที่ทำให้เข้าใจผิดว่าเกี่ยวข้องกับแบรนด์นั้น
ถ้าเจ้าของสิทธิ์ร้องเรียน Apple/Google จะถอดแอปโดยแทบไม่ถามอะไรเลย

## 8.2 ทางเลือกสามทาง เรียงจากปลอดภัยที่สุด

### ทาง A — ขออนุญาตค่ายอย่างเป็นทางการ (ดีที่สุด)

ส่งอีเมลหา iAM (ช่องทางติดต่อในเว็บทางการ / เพจเฟซบุ๊ก BNK48) ขอ
"อนุญาตใช้ภาพและเครื่องหมายการค้าเพื่อจัดทำแอปพลิเคชันฐานข้อมูลโดยแฟนคลับ
แบบไม่แสวงหากำไร" ร่างสั้น ๆ:

```
เรียน ฝ่ายลิขสิทธิ์ บริษัท อิสระในการจัดการศิลปิน จำกัด

ผม/ดิฉัน [ชื่อ] เป็นผู้จัดทำแอปพลิเคชัน 48thDB ซึ่งเป็นฐานข้อมูลสมาชิก
ตารางงาน และผลงานเพลงของ BNK48 และ CGM48 จัดทำโดยแฟนคลับ ให้ใช้งานฟรี
ไม่มีโฆษณาและไม่มีรายได้ทุกรูปแบบ (เว็บไซต์: https://48thdb.web.app)

ขออนุญาตใช้ภาพโปรไฟล์สมาชิกและชื่อวงในแอปพลิเคชัน โดยจะระบุอย่างชัดเจนว่า
เป็นแอปที่จัดทำโดยแฟนคลับ ไม่ใช่แอปทางการ และยินดีปฏิบัติตามเงื่อนไข
หรือถอดเนื้อหาส่วนใดออกทันทีที่บริษัทแจ้ง

หากบริษัทมีแนวทางหรือเงื่อนไขสำหรับสื่อที่จัดทำโดยแฟนคลับ
ขอความกรุณาแจ้งให้ทราบด้วยครับ/ค่ะ

ขอแสดงความนับถือ
[ชื่อ] [อีเมล] [เบอร์โทร]
```

ได้อนุญาตเป็นลายลักษณ์อักษรเมื่อไหร่ **เก็บอีเมลนั้นไว้** แนบให้ Apple ได้ทันทีที่ถูกถาม
เริ่มส่งตั้งแต่วันนี้ เพราะกว่าจะได้คำตอบอาจเป็นเดือน

### ทาง B — ปล่อยแบบแฟนเมด พร้อมกันไว้ให้มากที่สุด

ถ้ายังไม่ได้คำตอบ และยังอยากปล่อย ทำอย่างน้อยทั้งหมดนี้:

1. **เขียน disclaimer ให้เห็นชัด** — ในหน้าเกี่ยวกับแอป, ในคำบรรยายสโตร์, ในหน้าแรกครั้งแรกที่เปิด
   ```
   แอปนี้จัดทำโดยแฟนคลับ (fan-made) ไม่ใช่แอปพลิเคชันทางการ
   ไม่มีส่วนเกี่ยวข้องกับ BNK48, CGM48 หรือบริษัท อิสระในการจัดการศิลปิน จำกัด
   ภาพและเครื่องหมายการค้าทั้งหมดเป็นของเจ้าของสิทธิ์
   ```
2. **ห้ามใช้ชื่อ/โลโก้วงเป็นชื่อแอปหรือไอคอน** — `48thDB` ปลอดภัยกว่า `BNK48 Database` มาก
   ไอคอนต้องเป็นงานที่คุณออกแบบเอง ไม่ใช่โลโก้วง
3. **ห้ามหารายได้** ทุกรูปแบบ ไม่มีโฆษณา ไม่มี in-app purchase ไม่มีบริจาค
   (ทันทีที่มีเงินเข้ามา จุดยืน "แฟนเมดไม่แสวงหากำไร" หายไปทันที)
4. **มีช่องทางแจ้งลบ (takedown)** ระบุอีเมลไว้ในหน้าเกี่ยวกับ และลบให้เร็วเมื่อถูกแจ้ง
5. **ลิงก์กลับช่องทางทางการ** ในหน้าเมมเบอร์ ลิงก์ไป X/IG ทางการของน้อง
   แสดงเจตนาที่ดีและเป็นประโยชน์ต่อค่าย

### ทาง C — เลี่ยงรูปทางการทั้งหมด

- ใช้ภาพเวกเตอร์/ภาพประกอบที่วาดเอง หรืออักษรย่อในวงกลมสีประจำทีมแทนรูปถ่าย
- ดึงรูปสดจาก API/ฟีดทางการตอนรันไทม์แทนที่จะฝังในแอป (ฝังคือการทำซ้ำ)
- จุดแข็งของแอปยังอยู่ครบ: ตารางงาน ตำแหน่งเซมบัตสึ วันเกิด ประวัติทีม

**คำแนะนำของผม**: เริ่ม A ทันที ทำ B ให้ครบทุกข้อระหว่างรอ และเตรียมแผน C ไว้ในใจ
ถ้าค่ายปฏิเสธหรือแจ้งให้ถอด — และที่สำคัญ **อย่าเพิ่งลงทุนซื้อบัญชี Apple $99
ก่อนตัดสินใจเรื่องนี้ให้จบ**

## 8.3 PDPA — กฎหมายคุ้มครองข้อมูลส่วนบุคคลของไทย

แอปคุณเก็บอีเมล ชื่อ และ user id = เป็น "ผู้ควบคุมข้อมูลส่วนบุคคล" ตาม PDPA
สิ่งที่ต้องมี:

- **ประกาศความเป็นส่วนตัว (Privacy Policy)** ที่เข้าถึงได้ก่อนสมัคร
- **ฐานทางกฎหมาย** ในการเก็บ (กรณีนี้คือความยินยอม — ให้ติ๊กยอมรับตอนสมัคร)
- **สิทธิของเจ้าของข้อมูล**: ขอดู ขอแก้ ขอลบ ขอถอนความยินยอม
  → ปุ่มลบบัญชีที่ทำใน `02-prep-web.md` §5.2 ครอบคลุมส่วนนี้แล้ว
- **ช่องทางติดต่อ** อีเมลที่ติดต่อได้จริง
