## สรุปสั้นที่สุด ถ้าอ่านได้บรรทัดเดียว

เว็บนี้ขึ้นแอปสโตร์ได้จริง วิธีที่คุ้มที่สุดคือ **ห่อโค้ดเดิมด้วย Capacitor**
ไม่ต้องเขียนใหม่ แต่มีสองด่านที่ทำให้ถูกปฏิเสธได้ และต้องเตรียมตั้งแต่วันนี้

1. **Apple Guideline 4.2** — แอปที่เป็นแค่เว็บห่อกล่อง โดนตีตก
   ต้องมีของที่เว็บทำไม่ได้ (แจ้งเตือนวันเกิด/งาน, วิดเจ็ต, ออฟไลน์เต็มรูปแบบ) → ดู `04-native.md`
2. **ลิขสิทธิ์** — รูปและชื่อ BNK48 / CGM48 เป็นทรัพย์สินของค่าย (iAM)
   แอปแฟนเมดที่ใช้รูปทางการโดยไม่ได้รับอนุญาต โดนถอดได้ทุกเมื่อ → ดู `08-legal.md`

ข้อ 2 สำคัญกว่าข้อ 1 เพราะแก้โค้ดไม่ได้ ต้องแก้ด้วยการขออนุญาตหรือเปลี่ยนวิธีใช้รูป
ควรเริ่มติดต่อค่ายตั้งแต่ตอนนี้ ระหว่างที่ทำส่วนเทคนิคไปด้วย
