# ป้าย "กำลังไลฟ์ใน iAM48" แบบสด

โค้ดในโฟลเดอร์นี้คือตัวกลางที่ไปถาม iAM48 ว่าใครกำลังไลฟ์อยู่ แล้วตอบกลับให้เว็บอ่านได้ทันที

## ทำไมต้องมี

เว็บเรียก `app.bnk48.com` จากเบราว์เซอร์ตรง ๆ ไม่ได้ เพราะฝั่งนั้นไม่ได้เปิด CORS เดิมจึงให้ GitHub Actions ไปถามแล้วเขียนลงไฟล์ `data/iam-live.json` แต่ cron ของ GitHub ถูกจำกัดหนักมาก (วัดจริงเมื่อ 21 ก.ย. 2026: ตั้งไว้ทุก 15 นาที รันจริงราว 5% ของที่ควรรัน) ไลฟ์ที่ยาว 20 นาทีจึงจบไปก่อนป้ายจะขึ้น

ตัวนี้รันบน Cloudflare Workers ซึ่งตอบทุกครั้งที่ถูกเรียก หน้าเว็บจะถามทุก 45 วินาที

**ไม่ได้บังคับ** ถ้าไม่ติดตั้ง เว็บก็ใช้ไฟล์จาก GitHub เหมือนเดิม และถ้าติดตั้งแล้ว Worker ล่ม เว็บจะถอยกลับไปใช้ไฟล์เองอัตโนมัติ

## ติดตั้ง (ครั้งเดียว ประมาณ 5 นาที)

1. สมัคร Cloudflare ฟรีที่ https://dash.cloudflare.com/sign-up (ไม่ต้องมีโดเมน ไม่ต้องผูกบัตร)

2. เปิด Terminal แล้วรันจากโฟลเดอร์นี้

   ```bash
   cd worker
   npx wrangler login      # เปิดเบราว์เซอร์ให้กดอนุญาต
   npx wrangler deploy
   ```

3. บรรทัดสุดท้ายจะบอก URL เช่น

   ```
   https://48thdb-iam-live.<ชื่อบัญชีคุณ>.workers.dev
   ```

4. เอา URL นั้นไปใส่ใน `index.html` ตรงบรรทัด

   ```js
   const IAM_LIVE_API = '';
   ```

   แล้ว commit ขึ้น GitHub เป็นอันเสร็จ

## ตรวจว่าทำงานไหม

```bash
curl 'https://48thdb-iam-live.<คุณ>.workers.dev/?debug=1'
```

ควรได้ JSON หน้าตาแบบนี้

```json
{ "checked": "2026-09-21T14:02:11.000Z",
  "live": [ { "id": "cgm-namphet", "caption": "ทำคุกกี้", "url": "https://app.bnk48.com/member-playback/1" } ],
  "known": 58, "members": 58,
  "debug": { "slice": 1, "slices": 3, "asked": 24, "failed": 0 } }
```

- `live` คือคนที่กำลังไลฟ์
- `known` คือจำนวนคนที่เพิ่งเช็กไปและยังถือว่าข้อมูลสด
- ถ้า `failed` สูงแปลว่า iAM48 ปฏิเสธคำขอ ให้ลองใหม่อีกครั้ง

## ข้อจำกัดที่ต้องรู้

- **แผนฟรีของ Cloudflare ยิงต่อได้ 50 ครั้งต่อการเรียกหนึ่งครั้ง** แต่มีสมาชิก 58 คน จึงถามทีละ 24 คนสลับกันไป วนครบทุกคนในราวหนึ่งนาที ป้ายจึงช้าได้ประมาณ 1 นาที ไม่ใช่เป็นชั่วโมงแบบเดิม
- **โควตาฟรี 100,000 ครั้งต่อวัน** หน้าเว็บถามทุก 45 วินาทีเฉพาะตอนเปิดแท็บอยู่ ถ้ามีคนเปิดค้างพร้อมกัน 10 คนตลอดวันจะใช้ราว 19,000 ครั้ง ยังเหลือเยอะ
- **cron ใน `wrangler.toml`** ให้ Worker หมุนเช็กเองทุก 2 นาทีช่วง 17:00–01:00 น. เพื่อให้คนแรกที่เข้าเว็บเจอข้อมูลครบเลย ถ้าไม่อยากได้ ลบสองบรรทัดท้ายไฟล์ออก
- Worker นี้ทำเฉพาะไลฟ์ iAM48 ส่วนไลฟ์ YouTube ยังใช้ GitHub Actions เหมือนเดิม เพราะต้องใช้คีย์ API และมีโควตาจำกัดกว่า

## แก้ไขภายหลัง

แก้ไฟล์ `iam-live-worker.js` แล้วรัน `npx wrangler deploy` ซ้ำ ถ้าจะเลิกใช้ ให้ลบ URL ออกจาก `IAM_LIVE_API` ในหน้าเว็บ (เว็บกลับไปใช้ไฟล์เดิม) แล้วรัน `npx wrangler delete` ถ้าต้องการลบ Worker ทิ้ง
